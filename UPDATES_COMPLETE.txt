📊 DATABASE REQUIREMENTS:

Ensure these tables exist in Supabase:

1. users table
   - id (primary key)
   - email (unique)
   - full_name
   - phone
   - referral_code
   - security_pin
   - fingerprint_enabled
   - profile_picture_url
   - is_verified
   - created_at, updated_at

2. otp_tokens table
   - id (primary key)
   - email
   - code
   - expires_at
   - created_at
